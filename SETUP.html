Setup de Print3D

Seguí estos 4 pasos. Toma ~15 minutos la primera vez.

1Crear cuenta en Supabase

Entrá a supabase.com y creá una cuenta gratuita.

Creá un nuevo proyecto. Elegí un nombre (ej: print3d), una contraseña fuerte para la base de datos, y la región más cercana (South America si está disponible).

Esperá ~2 minutos a que el proyecto termine de configurarse.

2Crear las tablas

En el panel de Supabase, andá a SQL Editor (ícono de base de datos en el sidebar izquierdo).

Abrí el archivo supabase_schema.sql que está en la carpeta del proyecto, copiá todo el contenido y pegalo en el editor.

Hacé clic en Run. Deberías ver "Success" al final.

Esto crea todas las tablas, los permisos de seguridad y el bucket de almacenamiento para los STL.
3Configurar las variables de entorno

En Supabase, andá a Settings → API. Necesitás dos valores:

  • Project URL — empieza con https://xxxxx.supabase.co
  • anon public key — la clave larga que empieza con eyJ...

En la carpeta del proyecto, creá un archivo llamado .env con este contenido:

VITE_SUPABASE_URL=https://TU-PROYECTO.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
El archivo .env nunca se comparte ni se sube a GitHub — contiene tus claves privadas.
4Crear usuarios y arrancar la app

En Supabase, andá a Authentication → Users → Add user. Creá los dos usuarios (vos y tu socio) con email y contraseña.

Ahora abrí una terminal (CMD o PowerShell) en la carpeta del proyecto y ejecutá:

npm install
npm run dev

Abrí el navegador en http://localhost:5173 e ingresá con tu usuario.

La app corre localmente en tu PC. Para subirla a la nube (Vercel) y acceder desde cualquier lugar, avisame y te preparo las instrucciones en el siguiente paso.
